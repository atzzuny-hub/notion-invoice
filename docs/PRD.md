# 견적서 공유 서비스 MVP PRD

## 🎯 핵심 정보

**목적**: Notion에 입력된 견적서를 관리자는 공유 링크로 손쉽게 전달하고, 클라이언트는 로그인 없이 웹에서 열람·PDF 다운로드할 수 있게 한다.
**사용자**: Notion으로 견적서를 관리하는 1인 프리랜서/소규모 사업자(관리자)와, 링크로 견적서를 받는 고객사 담당자(클라이언트).

## 🚶 사용자 여정

```
[관리자 플로우]
1. 로그인 페이지
   ↓ 이메일/비밀번호 로그인 성공

2. 견적서 목록 페이지 (관리자 홈, 자동 리디렉션 도착지)
   ↓ 특정 견적서 행의 "링크 복사" 버튼 클릭

3. 공유 링크가 클립보드에 복사됨 (토스트 알림)
   ↓ 관리자가 이메일/메신저 등 서비스 외부 채널로 링크를 고객에게 전달

4. [세션 종료 또는 목록으로 계속 작업]

---

[클라이언트 플로우]
1. 공유 링크(고유 토큰 포함) 클릭
   ↓ 토큰 유효성 검증

   [토큰 유효 + 만료 전]  → 견적서 열람 페이지 → 내용 확인 → "PDF 다운로드" 클릭 → PDF 파일 저장
   [토큰 무효/만료]       → 유효하지 않은 링크 페이지 → (관리자에게 재요청 안내)
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | Notion 견적서 목록 조회 | Notion 데이터소스(data source)에서 견적서 목록을 불러와 표시 | 관리자가 자신이 만든 견적서를 웹에서 확인하는 핵심 진입점 | 견적서 목록 페이지 |
| **F002** | 견적서 상태 배지 표시 | Notion의 상태 필드(임시저장/발송완료)와 유효기간 비교 결과(기한만료 여부)를 배지로 표시 | 어떤 견적서를 클라이언트에게 보낼지/재발행할지 판단 근거 | 견적서 목록 페이지 |
| **F003** | 공유 링크 확인 및 복사 | 견적서별 고유 토큰이 포함된 공유 URL을 확인하고 클립보드로 복사 | 클라이언트에게 견적서를 전달하는 유일한 통로 | 견적서 목록 페이지 |
| **F004** | 클라이언트 견적서 웹 렌더링 | 공유 토큰으로 접근 시 고객명·견적 항목·수량·단가·합계·유효기간을 보기 좋게 렌더링 | 클라이언트가 실제로 견적 내용을 확인하는 서비스의 핵심 가치 | 견적서 열람 페이지 |
| **F005** | 견적서 PDF 다운로드 | 열람 중인 견적서를 PDF 파일로 즉시 다운로드 | 클라이언트가 견적서를 보관·전달·인쇄하기 위한 필수 산출물 | 견적서 열람 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F006** | 공유 링크 유효성 검증 | 토큰 존재 여부·만료일(유효기간) 초과 여부를 검사해 접근 가능 여부 결정 | 인증 없는 공개 링크 구조에서 최소한의 접근 제어 및 오류 안내에 필수 | 견적서 열람 페이지, 유효하지 않은 링크 페이지 |
| **F010** | 관리자 인증 (로그인/로그아웃) | 단일 운영자 계정으로 로그인/로그아웃만 지원 (회원가입 없음) | 견적서 목록·공유 링크는 관리자만 볼 수 있어야 하는 최소 보호 장치 | 로그인 페이지, 견적서 목록 페이지 |

### 3. MVP 이후 기능 (제외)

- 웹에서 견적서 직접 작성/수정 (Notion에서만 관리)
- 견적서 검색·정렬·고급 필터링
- 클라이언트 열람/서명 여부의 Notion 자동 반영(상태 write-back)
- 결제/전자서명 연동
- 이메일/카카오톡 등 링크 자동 발송·알림
- 다국어 지원
- 견적서 버전 관리/이력 조회

## 📄 페이지별 상세 기능

### 로그인 페이지

> **구현 기능:** `F010` | **메뉴 위치:** 비로그인 상태 최상위

| 항목 | 내용 |
|------|------|
| **역할** | 관리자 전용 인증 진입점 |
| **진입 경로** | 비로그인 상태에서 보호된 페이지 접근 시 자동 리디렉션, 또는 직접 접속 |
| **사용자 행동** | 이메일과 비밀번호를 입력하고 로그인 |
| **주요 기능** | • 이메일/비밀번호 로그인 폼<br>• 인증 실패 시 에러 메시지 표시<br>• **로그인** 버튼 |
| **다음 이동** | 성공 → 견적서 목록 페이지, 실패 → 에러 메시지 표시 후 페이지 유지 |

---

### 견적서 목록 페이지

> **구현 기능:** `F001`, `F002`, `F003`, `F010` | **인증:** 관리자 로그인 필수

| 항목 | 내용 |
|------|------|
| **역할** | 관리자가 로그인 후 처음 만나는 홈이자 유일한 업무 화면 |
| **진입 경로** | 로그인 성공 시 자동 리디렉션, 이후 관리자 메뉴에서 상시 접근 |
| **사용자 행동** | Notion에 등록된 견적서 목록을 확인하고, 원하는 견적서의 공유 링크를 복사해 클라이언트에게 전달 |
| **주요 기능** | • Notion 데이터소스 연동 견적서 목록 표시(고객명, 견적번호, 합계금액, 유효기간)<br>• 상태 배지 표시(임시저장/발송완료/기한만료)<br>• 견적서별 **링크 복사** 버튼(고유 토큰 URL을 클립보드에 복사)<br>• **로그아웃** 버튼 |
| **다음 이동** | 링크 복사 후 같은 페이지 유지(토스트 알림), 로그아웃 → 로그인 페이지 |

---

### 견적서 열람 페이지

> **구현 기능:** `F004`, `F005`, `F006` | **인증:** 없음 (공유 토큰 기반 접근)

| 항목 | 내용 |
|------|------|
| **역할** | 클라이언트가 견적 내용을 확인하는 공개 열람 화면 |
| **진입 경로** | 관리자가 전달한 고유 토큰이 포함된 공유 링크로 직접 접속 (메뉴 없음) |
| **사용자 행동** | 견적 항목·수량·단가·합계·유효기간을 확인하고, 필요 시 PDF로 다운로드 |
| **주요 기능** | • 토큰 유효성 검증(만료일 확인)<br>• 고객명·견적번호·발행일·유효기간 표시<br>• 견적 항목 테이블(항목명, 수량, 단가, 금액) 및 합계금액 표시<br>• **PDF 다운로드** 버튼 |
| **다음 이동** | 토큰 유효 → 페이지 내 콘텐츠 렌더링 유지, 토큰 무효/만료 → 유효하지 않은 링크 페이지로 전환 표시 |

---

### 유효하지 않은 링크 페이지

> **구현 기능:** `F006` | **인증:** 없음 (공유 토큰 기반 접근)

| 항목 | 내용 |
|------|------|
| **역할** | 만료되었거나 존재하지 않는 공유 링크에 대한 안내 화면 |
| **진입 경로** | 견적서 열람 페이지에서 토큰 검증 실패 시 자동 전환 |
| **사용자 행동** | 링크가 만료/무효임을 확인하고 관리자에게 재발급을 요청 |
| **주요 기능** | • 만료/무효 사유 안내 메시지<br>• 관리자 문의 안내 문구 |
| **다음 이동** | 없음 (관리자가 새 링크를 전달할 때까지 대기) |

## 🗄️ 데이터 모델

> 물리적 저장소는 Notion 데이터소스(2025-09-03 데이터소스 모델, `data_source_id` 기준)이며, 아래는 그 논리 스키마다.

### 견적서 데이터소스 (Quote)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | Notion 페이지 ID | Notion Page ID |
| 견적번호 | 견적서 고유 번호 | Text |
| 고객 | 견적 대상 고객 | → 고객 데이터소스.id (Relation) |
| 발행일 | 견적서 발행일 | Date |
| 유효기간 | 견적 유효 만료일 | Date |
| 상태 | 임시저장 / 발송완료 | Select |
| 공유토큰 | 공유 링크용 고유 토큰 | Text (Unique) |
| 합계금액 | 견적 항목 합계 | Number |

### 견적 항목 데이터소스 (Quote Item)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | Notion 페이지 ID | Notion Page ID |
| 견적서 | 소속 견적서 | → 견적서 데이터소스.id (Relation) |
| 항목명 | 견적 품목/작업명 | Text |
| 수량 | 수량 | Number |
| 단가 | 단가 | Number |
| 금액 | 수량 × 단가 | Number (Formula/Rollup) |

### 고객 데이터소스 (Client)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | Notion 페이지 ID | Notion Page ID |
| 고객명 | 담당자명 | Text |
| 회사명 | 고객사명 | Text |
| 이메일 | 연락용 이메일 | Text |
| 연락처 | 전화번호 | Text |

## 🛠️ 기술 스택 (최신 버전)

### 🎨 프론트엔드 프레임워크

- **Next.js 16** (App Router · Turbopack) - React 풀스택 프레임워크
- **TypeScript 5.6+** (strict) - 타입 안전성 보장
- **React 19** - UI 라이브러리 (최신 동시성 기능)

### 🎨 스타일링 & UI

- **TailwindCSS v4** (CSS-first, 설정파일 없는 새로운 엔진) - 유틸리티 CSS 프레임워크
- **shadcn/ui** (`radix-nova` 스타일, `radix-ui` 통합 패키지 기반) - 고품질 React 컴포넌트 라이브러리
- **Lucide React** - 아이콘 라이브러리
- **next-themes** - 다크모드 지원

### 🗄️ 데이터 백엔드 (Notion)

- **@notionhq/client** - Notion 공식 SDK
- **Notion REST API** (2025-09-03 데이터소스 모델) - `database_id`가 아닌 `data_source_id`로 견적서/견적항목/고객 데이터소스를 조회·참조

### 📄 PDF 생성

- **@react-pdf/renderer** - React 컴포넌트 기반 PDF 문서 생성 (서버리스 환경에서 헤드리스 브라우저 없이 동작해 Vercel 배포에 적합)

### 📝 폼 & 검증

- **React Hook Form 7.x** - 로그인 폼 상태 관리
- **Zod** - 입력값·토큰 검증 스키마

### 🚀 배포 & 호스팅

- **Vercel** - Next.js 16 최적화 배포 플랫폼

### 📦 패키지 관리

- **npm** - 의존성 관리
